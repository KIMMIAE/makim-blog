# 구역별 구현 기록

## 1. 홈 히어로

- 실제 홈에 확정한 제목과 소개 문구, 글 둘러보기, 기존 소개 페이지 링크를 추가했다.
- `src/components/home/HomeHero.tsx`와 CSS 모듈은 공통 디자인 토큰을 사용한다.
- 선택한 C 고양이 SVG를 `public/cat/`에 추가했다. React 컴포넌트에서 hover, 드래그, 잠들기, 키보드 들기/내리기, Escape, 포인터 취소 및 reduced-motion을 처리한다.
- 홈의 h1은 히어로 제목으로 정리하고, 기존 최근 글 제목은 h2로 변경했다.
- 검증: lint, Webpack 프로덕션 빌드 통과. 실제 브라우저에서 데스크톱 배치, 키보드 토글, 드래그 후 복귀, 다크 모드를 확인했다. 모바일은 반응형 CSS를 추가했으나 아직 기기별 시각 검증 전이다.
- 로컬 확인: 빌드 후 `npm run start -- --hostname 127.0.0.1 --port 3000`, http://127.0.0.1:3000/

다음 작업은 헤더(Still Making 로고·내비게이션), 이후 최근 기록과 주제별 영역이다. 웹폰트는 아직 시스템 폰트를 사용하며, 라이선스 파일을 포함하는 작업이 남아 있다. 전체 페이지 리디자인은 완료되지 않았다.
