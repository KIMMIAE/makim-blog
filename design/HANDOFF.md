# Still Making 홈 구현 인수인계

## 먼저 볼 화면

이 문서만 읽고 새 디자인을 추측하지 말고, HTML 시안을 브라우저로 열어 실제 배치와 상호작용을 확인한다.

```sh
git switch codex/still-making-redesign
python3 -m http.server 4317 --bind 127.0.0.1 --directory design/pixel-cat
```

이미 4317 포트에서 서버가 실행 중이면 새로 실행하지 않고 아래 주소를 연다.

- 홈 시안: http://127.0.0.1:4317/home/
- 확정 고양이와 자세·드래그 체험: http://127.0.0.1:4317/poses/

localhost 주소는 서버가 실행 중인 컴퓨터에서만 접근할 수 있다. 다른 컴퓨터나 클라우드 환경에서는 이 브랜치의 파일을 가져와 위 명령으로 직접 서버를 실행해야 한다. 아직 원격으로 push하지 않은 커밋은 다른 컴퓨터에 자동으로 전달되지 않는다.

## 구현 기준과 작업 범위

1. `design/pixel-cat/home/index.html`을 시각적 기준으로 사용한다. 실제 `src/app/page.tsx`에는 히어로만 적용했다. 헤더·최근 기록·주제·소개 영역은 후속 작업이다.
2. `design/README.md`의 확정 사항과 `styles/tokens.css`, `styles/theme.css`를 읽는다. 시안의 인라인 CSS를 그대로 복제하기보다 공통 토큰으로 연결한다.
3. 고양이는 `design/pixel-cat/selection.json`의 확정 C안과 `design/pixel-cat/poses/c-*.svg`만 사용한다. A 및 round/tabby/cute/soft 폴더는 작업 이력이며 최종 선택이 아니다. 생성 스크립트가 이전 폴더를 참조하므로 임의로 삭제하지 않는다.
4. 원본 고양이 사진은 저장소에 포함되어 있지 않다. 확정한 고양이 SVG를 구현에 사용한다.
5. 기존 글 데이터와 글 URL, 태그, 다크 모드 기능을 유지하며 실제 Next.js 홈에 적용한다. 시안의 글은 두 개를 수동 배치한 것이므로 실제 홈에서는 기존 데이터 함수를 사용한다.
6. 시안의 주제 링크는 현재 모두 태그 목록으로 연결되어 있다. 실제 구현 시 존재하는 태그와 콘텐츠에 맞춰 연결하고, 가짜 카테고리나 게시글을 만들지 않는다.
7. 웹폰트는 아직 추가하지 않았다. 후보는 LINE Seed KR와 Pretendard이며, 선택한 배포본의 상업적 사용 조건을 확인하고 라이선스 및 저작권 고지를 함께 보관한다. 시안은 시스템 폰트를 사용한다.
8. 로고는 CSS 원 두 개로 자체 작성했다. 보라 `#8B5CF6`와 주황 `#FB923C`(불투명도 75%)를 겹친다. 외부 브랜드의 로고 파일을 사용한 것이 아니며 상표 유사성 조사는 하지 않았다.

## 확인할 동작

- 고양이 hover: 갸웃. 마우스 드래그: 들어 올린 자세. 놓기: 잠깐 잠든 뒤 앉기.
- 키보드: 고양이에 초점 후 Enter/Space로 들기 전환, Escape로 복귀.
- Read more: hover와 키보드 focus 모두에서 화살표 표시.
- 작은 화면에서 가로 넘침 없이 재배치. reduced-motion 설정 존중.
- 다크 색상 토큰은 초안이며 다크 홈 화면은 아직 시각적으로 확정하지 않았다.

## 검증과 커밋

작업 단위별로 변경 내용과 검증 결과를 정리하고 커밋한다. 디자인 확정사항을 변경할 때에는 문서도 갱신한다. 기존 사용자 작업은 보존한다.

현재 토큰 단계에서 `npm run lint`와 `npm run build -- --webpack`을 통과했다. 기본 `npm run build`는 이 실행 환경에서 Turbopack의 포트 생성 권한 오류로 실패했다. 기본 빌드 설정을 바꾸지는 않았다.

## 다른 에이전트에게 전달할 요청

> `codex/still-making-redesign` 브랜치에서 `design/HANDOFF.md`와 `design/README.md`를 읽어줘. 인수인계 문서대로 로컬 서버를 열고 `/home/`과 `/poses/`를 브라우저로 확인해. 그 화면과 확정한 C 고양이를 기준으로 실제 Next.js 블로그 홈을 구현해줘. 공통 디자인 토큰을 사용하고, 서체 라이선스와 기존 글·태그·다크 모드를 고려해. 작업 단위별로 검증 내용을 정리하고 커밋해줘.
