# Pretendard (OG 이미지 생성 전용)

- 출처: https://github.com/orioncactus/pretendard (v1.3.9), 저작권 Kil Hyung-jin
- 라이선스: SIL Open Font License 1.1 (`LICENSE.txt`). 상업적 사용·재배포 허용, 폰트 단독 판매 금지
- 용도: `src/lib/og/` 의 `next/og` ImageResponse 가 1200×630 공유 카드를 그릴 때만 사용한다.
  사이트 본문에는 웹폰트로 적용하지 않았다(시스템 서체 사용). 적용하려면 별도 결정 필요
- 파일: `Pretendard-Bold.woff`(제목), `Pretendard-SemiBold.woff`(메타). satori 는 woff2 를 못 읽어 woff 를 쓴다
